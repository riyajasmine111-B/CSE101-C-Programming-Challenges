# Student Marks Calculator

This is a simple C program that calculates a student's:

* Total marks
* Average marks
* Percentage

## How it works

The program takes marks for **5 subjects** as input and then calculates the total, average, and percentage.

## Formula

```text
Total = Sum of 5 subject marks
Average = Total / 5
Percentage = (Total / 500) × 100
```

## Language Used

* C

## How to Run

```bash
gcc marks.c -o marks
./marks
```
